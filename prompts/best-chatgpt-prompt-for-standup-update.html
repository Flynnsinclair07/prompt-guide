ChatGPT Prompt for a Standup Update

Yesterday's messy work notes → a tight standup update. Yesterday, today, blockers. Three lines max.

Updated May 2026.

The best ChatGPT prompt for a daily standup update compresses yesterday's work into a 3-line format (yesterday / today / blockers), strips filler, and forces a real blocker named or a deliberate "no blockers." Works for async Slack standups and live ones.

The Prompt
You are an experienced tech-lead who has heard 1,000 standups and knows the difference between a useful update and noise.

YESTERDAY'S RAW WORK (bullet dump — what you did, what you read, what got pushed back): [PASTE]
TODAY'S PLAN (rough — what you're working on): [PASTE]
BLOCKERS or open questions (be honest — "none" is OK): [PASTE]
TEAM CONTEXT (sprint goal / current focus / what your team cares about): [PASTE]
FORMAT (Slack async / live daily / written weekly): [PASTE]

HARD RULES:
1. Three lines max: yesterday / today / blockers.
2. Cut filler. "Worked on the ticket" = nothing. "Shipped the migration script + reviewed Maria's PR" = something.
3. Blockers must be specific. "Waiting on design" with no name = avoidance. "Waiting on Priya for the new icon set; pinged Mon + Wed" = real.
4. Banned: "continued working on," "still on," "ongoing," "various," "looking into."
5. If TODAY ties to the sprint goal, name the connection. If not, flag the misalignment.

OUTPUT IN ORDER:
A. The standup update (3 lines).
B. The one sentence I should add only if a blocker is real and the team can help.
C. A note flagging if today's plan drifts from the sprint goal.

How to Use This Prompt

  1. Copy the prompt and fill in the bracketed sections with your real details.
  2. Be specific. Vague input produces vague output.
  3. Paste into ChatGPT, Claude, or Gemini and read the output before using it.
  4. Edit the draft in your own voice before sending or submitting.

Example Output

Async Slack standup (from a real run):

Yesterday: Shipped the rollback script for the billing migration; reviewed Maria's PR on the auth layer.

Today: Pairing with Priya on the cutover plan, target draft by EOD.

Blockers: Waiting on the staging DB credentials from Infra (Slacked Jamie Mon + Wed, no reply yet).

Tips to Get Better Results

  • Standups are 90 seconds. The audience is your teammates, not your manager. Optimize for what they need to know to do their work.
  • If you have no blocker, say so explicitly. "No blockers" is more useful than vague reassurance.
  • Skip the "I started yesterday and continued today" pattern. Treat the standup as an update, not a journal.
  • If a real blocker exists, name a specific person and a specific ask. "Pinged X" beats "waiting on someone."
