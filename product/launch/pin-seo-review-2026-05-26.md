# Pinterest pin description SEO review — 2026-05-26

Scanned all 20 batch-2 pin descriptions in `pins/PINS-BATCH-2.md` against Pinterest's known ranking factors (keyword in title, keyword in description, alt text, board fit, hashtags 4–8).

## Verdict
**Current descriptions are solid.** They follow the right pattern: lead with the benefit, name the tool (ChatGPT prompt), mention "free," include 6–8 relevant hashtags, link to the matching prompt page. Each pin's title is short, action-led, and keyword-bearing.

## Small tweaks worth doing eventually (not urgent)
- A few finance pins (pin-31 budgeting, pin-37 tax-prep) could add the year ("2026") to the description for seasonal lift. Pinterest favors recency for finance queries that spike Jan–Apr.
- Pin-23 (LinkedIn headline) and pin-28 (cold email) both have "stops the scroll" / "gets a reply" hooks that perform well historically — consider mirroring that pattern on pins that don't yet have a hook in the first line.
- Hashtag mix is reasonable; one or two pins lean too job-search-heavy (#jobsearch + #jobhunting + #careeradvice + #atsfriendly is overlap). Substitute one with a more specific tag (#linkedintips, #interviewquestions, #salaryNegotiation) for diversity.

## What NOT to do
- Don't keyword-stuff. Pinterest down-ranks pins that feel SEO'd over readable.
- Don't add #ad or #sponsored (not applicable; only required for actually-sponsored content).
- Don't lengthen descriptions past ~500 chars; Pinterest truncates.

## Conclusion
The pin batch is launch-ready as-is. Optional polish above is a 30-minute pass for post-launch, low priority.
