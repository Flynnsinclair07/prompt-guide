# 30-sec teaser video script — for after demo

Companion to the longer demo (`demo-video-script-only.md`). This is the 30-second cut for X, LinkedIn, and the Gumroad listing's hero loop. Record AFTER the main demo, with your real voice, when the congestion is gone.

## Spec
- **Length:** 28–32 seconds.
- **Aspect:** 9:16 (vertical) for X/LinkedIn/Pinterest. Re-export 16:9 horizontal for the Gumroad gallery.
- **Audio:** voice only. No music bed. The voice IS the value.
- **B-roll:** screen recording of the prompt running in ChatGPT, sped up 2x.

## The script (read at normal pace, ~28 sec total)

[0:00–0:04 — hard cut, screen blank]
*"Every ChatGPT resume prompt I tried did this..."*

[0:04–0:10 — screen recording of a generic AI-resume prompt's output, showing "spearheaded cross-functional synergy" and a made-up 40% metric, highlighted in red]
*"Numbers it invented. Phrases no recruiter actually reads."*

[0:10–0:16 — screen recording of the SnipPrompts resume prompt running, with the verification table appearing]
*"So I wrote prompts that refuse. Refuse to invent metrics. Refuse the clichés. Refuse to write the generic version."*

[0:16–0:22 — quick montage of 4 prompt pages: resume, cover letter, interview, salary]
*"One-forty free prompts. Four long-form guides. A paid bundle if you want every script and worksheet."*

[0:22–0:28 — full-screen URL]
*"snipprompts dot com. Built by one person in Colorado."*

## Notes
- Speak it before recording. Read it aloud three times so it sounds like *you saying it*, not reading.
- Don't try to be polished. The slight roughness is the brand.
- Cut hard, no fades. Faded transitions read as agency video; hard cuts read as builder video.
- Do not say "amazing," "incredible," "game-changing," "unlock." Banned.
- If your voice catches once or twice during the 28 seconds, that's fine — leave it. Polish is the wrong vibe.

## Export
- Vertical 9:16 (1080×1920): X, LinkedIn, Pinterest, Instagram Reels.
- Horizontal 16:9 (1920×1080): Gumroad gallery slot.
- Keep the file under 25MB so it inlines on every platform without a re-upload step.
